# Global Study — Спецификация дизайна

**Дата:** 2026-04-25
**Проект:** Веб-сайт на основе Telegram-канала @Globalstudyy
**Аудитория:** студенты 18–30 лет
**Язык UI:** только русский

---

## Стек

| Параметр | Решение |
|---|---|
| Frontend | HTML + CSS + Vanilla JS |
| Контент | `data/posts.json` (статический, обновляется вручную) |
| Хостинг | GitHub Pages |
| Акцент | Сине-фиолетовый градиент |
| Архитектура | Однофайловая (один index.html) |

---

## Структура файлов

```
global-study/
├── index.html
├── styles.css
├── app.js
├── data/
│   └── posts.json
└── images/
    └── (изображения постов)
```

---

## Формат данных (`posts.json`)

```json
[
  {
    "id": 1,
    "date": "2025-04-20",
    "category": "образование",
    "title": "Как получить грант на обучение за рубежом",
    "preview": "Краткое описание поста...",
    "text": "Полный текст поста...",
    "image": "images/post-1.jpg",
    "tags": ["гранты", "зарубеж", "финансирование"],
    "tg_link": "https://t.me/Globalstudyy/42"
  }
]
```

**Допустимые категории:** `образование`, `новости`, `возможности`, `ресурсы`

## Визуальная структура

### Шапка (фиксированная)
- Логотип «Global Study» слева
- Навигация: Главная / Новости / Образование / Возможности / Ресурсы
- Кнопка «Подписаться» справа → `https://t.me/Globalstudyy`
- На мобильном: бургер-меню

### Hero-блок
- Фон: сине-фиолетовый градиент
- Заголовок: «Всё для студента — в одном месте»
- Подзаголовок: краткое описание канала
- CTA: «Читать последние посты» (плавный скролл к ленте)

### Лента постов
- Сетка: 3 колонки (десктоп) → 2 (планшет) → 1 (мобильный)
- Карточка: изображение + категория-бейдж + дата + заголовок + превью + кнопка «Читать в Telegram»

### Фильтры
- Таблетки-кнопки: Все / Новости / Образование / Возможности / Ресурсы
- Строка поиска: фильтрация по `title`, `preview`, `tags` в реальном времени
- Фильтры комбинируются (категория + поиск работают одновременно)

### Блок подписки (над подвалом)
- Градиентный фон
- Текст: «Не пропускай новые посты — подпишись на канал»
- Кнопка: «Открыть Telegram»

### Подвал
- Логотип + слоган
- Ссылка: `https://t.me/Globalstudyy`
- Почта: `globalgo@gmail.com`
- Навигация (дублирует шапку)
- Копирайт: «© 2025 Global Study. Все права защищены.»

## Поведение (UX)

- `app.js` делает `fetch('data/posts.json')` при старте, рендерит карточки через `innerHTML`
- Фильтрация и поиск работают на клиенте, без перезагрузки страницы
- Карточки появляются с fade-in анимацией
- Плавный скролл к ленте из hero CTA

---

## SEO

- `<title>`, `<meta name="description">`, `<meta property="og:*">` в `index.html`
- Все `<img>` с `alt` на русском языке
- Семантические теги (`<header>`, `<main>`, `<article>`, `<footer>`)

---

## Обновление контента

1. Добавить новый объект в `data/posts.json`
2. Положить изображение в `images/`
3. `git add . && git commit -m "новый пост" && git push`
4. GitHub Pages публикует автоматически (~1 минута)
