# Hero-секция «Созвездие знаний» + liquid glass по сайту

Дата: 2026-07-08
Статус: утверждено пользователем в визуальном компаньоне (итерация 3)

## Цель

Заменить Vanta-глобус в Hero на кастомную композицию с фотофоном и частицами,
добавить сайту фирменные микровзаимодействия: анимированный курсор и
liquid-glass-эффект (в духе iOS 26) на кнопках и плитках.

## 1. Hero-секция (замена Vanta)

Слои снизу вверх:

1. **Фото**: библиотека (Unsplash `photo-1521587760476-6c12a4b040da`,
   `w=1800&q=80&auto=format`), `background-size: cover`, центрирование.
2. **Градиент-затемнение**: `linear-gradient(100deg, rgba(6,7,11,.94) 0%,
   rgba(6,7,11,.78) 40%, rgba(6,7,11,.30) 100%)` — текст слева всегда читаем.
   Одинаковый в светлой и тёмной теме (hero остаётся тёмным в обеих).
3. **Canvas-частицы «созвездие»**: ~85 золотых частиц (цвет `212,175,55`),
   дрейф + притяжение к курсору, линии между близкими частицами
   (порог `h * 0.22`), мерцание, радиальное золотое свечение вокруг курсора.
   Реализация: собственный canvas 2D, requestAnimationFrame.
   Vanta и его зависимость удаляются из Hero (пакеты `vanta` можно убрать,
   если больше нигде не используются).
4. **Контент** (grid 1.15fr / 0.85fr на desktop):
   - Слева: кикер, заголовок (вторая строка приглушённая `rgba(242,244,248,.55)`),
     подзаголовок, кнопки «Начать путь» (золотой градиент
     `linear-gradient(180deg,#e8c65a,#c9a22e)` + глянец) и «Университеты»
     (стекло: `rgba(255,255,255,.06)` + blur + светлая рамка).
   - Справа: три стеклянные плитки статистики.

### Стеклянные плитки статистики (hero)

- Содержимое: `500+ / студентов поступили`, `95% / одобренных виз`,
  `15 / стран для обучения`.
- Цифры крупные (clamp 22–40px), золотой градиент текста
  (`#ffe9a8 → #d4af37`), drop-shadow.
- Стекло: `backdrop-filter: blur(14px) saturate(1.3)`, рамка
  `rgba(255,255,255,.28)`, внутренние тени/блики, глянцевая полоса сверху
  (::before, blur 6px), хроматические отсветы по углам (::after —
  голубой/персиковый radial-gradient).
- Idle-анимация: плавное парение (translateY ±8px, 6s, разные фазы),
  плитки смещены по горизонтали (0 / +9% / −4%).

### Мобильная версия hero

- Одна колонка: текст сверху, плитки под текстом (горизонтально или стеком).
- Кастомный курсор и tilt-эффекты не активируются (см. §4).

## 2. Кастомный курсор (весь сайт)

- Золотая точка 8px (`#ffe9a8`, свечение) — следует за мышью мгновенно.
- Кольцо 38px (`rgba(212,175,55,.65)` рамка, лёгкий blur-фон) — догоняет
  точку с пружинной задержкой (`lerp 0.16`), поверх — пульс-волна
  (расширяющееся кольцо, 2s ease-out infinite).
- Над интерактивными элементами (a, button, плитки, карточки) кольцо
  расширяется до 64px и светлеет.
- Нативный курсор скрывается (`cursor: none`) только когда кастомный активен.
- Реализация: компонент `CustomCursor.tsx`, один rAF-цикл,
  `transform: translate(...)` без layout-трэшинга.

## 3. Liquid glass hover (iOS 26) — кнопки и плитки

Область применения:

- **Кнопки** (`Button.tsx` / `LinkButton`): пружинный scale 1.06
  (`cubic-bezier(.2,1.4,.4,1)`), у золотой — усиление глянца.
- **Плитки/карточки**: stat-плитки hero, счётчики Stats, карточки Services,
  Destinations, Universities (карусель), Posts, SuccessStories.

Эффект на плитках:

- 3D-tilt за курсором: rotateX до ±14°, rotateY до ±16°, scale 1.05,
  `perspective: 900px` на контейнере; возврат с пружиной .6s.
- Бегущий specular-блик: radial-gradient белого, следует за курсором,
  `mix-blend-mode: screen`, blur 4px, fade-in .35s.
- Усиление рамки и тени при hover (золотое свечение
  `0 0 40px -6px rgba(212,175,55,.28)`).
- Реализация: хук `useLiquidGlass()` (mousemove + rAF-троттлинг) +
  CSS-класс `liquid-glass`; переиспользуется всеми секциями.

## 4. Доступность и производительность

- Все эффекты (курсор, tilt, частицы) активны только при
  `(pointer: fine)` и выключены при `prefers-reduced-motion: reduce`.
- На тач-устройствах — стандартный курсор и обычные hover-фоллбеки.
- rAF-троттлинг mousemove; один общий цикл для курсора.
- Canvas частиц: cap DPR = 2.
- Фото hero: `loading` не критичен (above the fold), но добавить
  `<link rel="preload">` в index.html.

## 5. Вне объёма

- Секции FAQ, CTA, Header/Footer структурно не меняются
  (кнопки в них получают эффект автоматически через Button).
- Stats-секция сохраняет анимированные счётчики — дубль цифр с hero допустим.
- Светлая тема: hero остаётся тёмным; остальные секции без изменений палитры.

## Критерии приёмки

1. Hero: фото библиотеки + частицы + плитки, Vanta удалён, тема
   переключается без пересоздания эффекта (hero тёмный всегда).
2. Курсор-точка + кольцо по всему сайту, расширение над интерактивом.
3. Tilt + specular на кнопках/плитках всех перечисленных секций.
4. На тач-устройствах и с reduced-motion — сайт полностью функционален
   без кастомных эффектов.
5. `bun run build` проходит; Lighthouse не деградирует критично
   (частицы ≤ 5% CPU на десктопе).
